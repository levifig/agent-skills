Tests compile source directly, and the capability receipts pin the committed binary's hash — so a stale artifact keeps both green. This is the third receipt re-record on one branch; the standing fix is already in intake: INTENT-20260719-decouple-installed-smoke-evidence-from-binary-rebuilds.

Remedy

Rebuild, re-run the three installed-smoke runners so receipts pin the final hash, commit binary + receipts together — the Before-Committing checklist's artifact rule, applied last-commit-wins. Then TASK-012's "carry the same binary as the receipts attest" box is true again at HEAD.

R2-2majorFreshness "re-run" ships as block-with-reason — contract and code disagree, and the V5 descope rides on ituser decides

Evidence

shape.md (Observable Workflow): "a receipt verified at an older commit triggers a criteria re-run at preflight rather than a block"; V5: "makes preflight re-run the declared criteria." Shipped and deliberately tested behavior: preflight blocks with receipt is not current (later non-receipt path requires criteria re-run) — fixture-confirmed after a plan.md-only commit; the V5 freshness tests assert the block string.

Adjudication of the TASK-014 descope

The implementer's untestable-as-written call is right under the broad reading of "editing plan.md does not [expire]" and honestly argued. But the narrow reading is testable against shipping code today: after a plan.md-only commit the reason is re-run, never digest mismatch (receipt expired) — the two strings are distinct surfaces. What is genuinely unsatisfiable is the auto-re-run sentence, and that is a contract question, not a fixture question.

Recommendation

Amend the contract to match the shipped behavior: release preflight executing arbitrary declared commands as a side effect — under --dry-run especially — is a footgun; block-with-mechanical-remedy is the safer design and one sentence of shape.md. Reword Decision 13/V5 to "a stale receipt blocks with a re-run demand; the receipt's own commit never stales," add the reason-string fixture, close TASK-014's box. Keep INTENT-20260727-exempt-plan-md-from-receipt-freshness-re-run alive as the UX refinement it is. Alternative: implement auto re-run as written. Shaping-tier either way — owner's call.
