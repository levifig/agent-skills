What this change does

Redefines Loaf's work unit — role-named narrative (brief.md? · shape.md · plan.md?/design.md?) settles at shaping; state (tasks/TASK-NNN-slug.md: commit-grained delegation packets, checkbox flips ride delivering commits) mutates during execution; machine metadata (change.json) carries identity plus an optional mutable target_release — and inverts the release gate onto release cohorts: the set of changes targeting a version must be executed and verified before that version cuts stable. Same root, both layouts coexist, progressive deprecation, repo mode complete (trackers own planning later; the gate reads git in every mode). And the change PR is the change's whole life: draft anchors shaping, implementation and reflect ride the same branch, main receives only completed changes — a shaped-but-unimplemented change is a shaped intent (D17).

⛔ Before — the proven defect

Merging a 411-line shaping document plus one frontmatter line opened a full stable release with zero lines implemented (worktree proof, 2026-07-25). And today's post-merge path can finalize a prerelease into stable with no gate at all.

✓ After — evidence or nothing

Preflight computes the candidate version first; a stable candidate gates its cohort: every member executed at flip grade (- [ ]→- [x], companion path outside docs/changes/) + fresh receipt, re-verified when stale. Finalization paths gate; prerelease candidates flow; retargets surface.
